# Setup Performance Tracker

Log every setup identified by the analyst and track actual outcomes to measure accuracy and improve the system.

## Usage

```
/track
```

This shows performance statistics for all tracked setups.

## What It Does

Tracks and analyzes:

✅ **All Identified Setups** logged to database
✅ **Entry/Exit Prices** if traded
✅ **Win Rate by Pattern** (which patterns work best?)
✅ **Win Rate by Score** (does 8/10 outperform 6/10?)
✅ **Average R:R Achieved** vs expected
✅ **Best Confluence Levels** (which zones most reliable?)
✅ **Time of Day Analysis** (when do setups work best?)
✅ **Symbol Performance** (best performing markets)

## How to Run

## Auto-Tracking

The system automatically logs:
- Every setup generated by analyst
- Entry price if bot trades it
- Exit price and outcome
- Actual vs expected R:R

No manual input required!

## Analysis Features

### Detailed Setup History
```bash
python scripts/performance_tracker.py --history GOLD
```

Shows all GOLD setups with outcomes.

### Pattern Analysis
```bash
python scripts/performance_tracker.py --pattern "Bullish Pullback"
```

Deep dive into specific pattern performance.

### Export to CSV
```bash
python scripts/performance_tracker.py --export
```

Download data for Excel analysis.

## Configuration

Data stored in: `data/setup_tracking.db`

Customize tracking in `config/tracking.json`:
```json
{
  "auto_track": true,
  "min_score_to_track": 5.0,
  "track_missed_setups": true,
  "retention_days": 365
}
```

## Tips

- Review weekly to see what's working
- Increase confidence in high-scoring setups
- Avoid patterns with low win rates
- Use data to refine entry criteria
- Share statistics with trading journal
